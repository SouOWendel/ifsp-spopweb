# 📘 Introdução ao Git
Neste material, você conhecerá os conceitos fundamentais do Git, um dos sistemas de controle de versão mais utilizados no mundo. Você aprenderá sua importância no desenvolvimento de software, como funciona o versionamento de arquivos e os principais comandos para iniciar o gerenciamento de projetos.

## Primeiros Passos com Git
Aprenda a instalar e configurar o Git em seu computador, criar repositórios, realizar commits e acompanhar o histórico de alterações. Este conteúdo fornecerá a base necessária para utilizar o Git no dia a dia.

- https://git-scm.com/cheat-sheet

##  GitHub
Neste conteúdo, você conhecerá o GitHub, plataforma utilizada para armazenar, compartilhar e colaborar em projetos utilizando Git. Serão apresentados os conceitos de repositórios remotos, branches, pull requests e boas práticas de colaboração.

## GitHub Desktop
Conheça o GitHub Desktop, ferramenta que facilita o uso do Git por meio de uma interface gráfica intuitiva. Você aprenderá a clonar repositórios, criar commits, sincronizar alterações e gerenciar branches sem utilizar o terminal.

- https://desktop.github.com/download/
- https://docs.github.com/pt/desktop
